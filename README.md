## Общее описание

Консольный (CLI) эмулятор языка оболочки UNIX-подобной ОС на Java 17+.
Приглашение к вводу содержит имя VFS: `[vfs]$ `.

Реализовано на данный момент:

- этап 1 (REPL): интерактивный цикл, парсер с аргументами в кавычках,
  команды-заглушки `ls`, `cd`, команда `exit`;
- этап 2 (конфигурация): параметры командной строки, стартовый скрипт,
  отладочный вывод всех параметров при запуске.

Физический файл VFS на этом этапе **не читается** (загрузка VFS — этап 3):
путь только выводится в отладочной информации, а из имени файла (без
последнего расширения) формируется имя VFS для приглашения.

## Функции

| Команда | Описание |
|---------|----------|
| `ls [арг...]` | Заглушка: печатает имя команды и аргументы |
| `cd [арг...]` | Заглушка: печатает имя команды и аргументы |
| `exit` | Завершает работу эмулятора |

Правила разбора строки:

- аргументы разделяются пробелами и табуляциями;
- `"..."` — аргумент с пробелами; внутри допустимы `\"` и `\\`;
- `'...'` — всё внутри берётся буквально;
- `\ ` вне кавычек экранирует следующий символ;
- `""` — пустой аргумент.

Ошибки: незакрытая кавычка выводит `error: ...`, неизвестная команда —
`<имя>: command not found`. Эмулятор после ошибки продолжает работу.

## Настройки (параметры командной строки)

| Параметр | Описание |
|----------|----------|
| `--vfs <путь>` | Путь к физическому расположению VFS. По имени файла строится приглашение: `demo.json` → `[demo]$ `. Без параметра имя VFS — `vfs` |
| `--script <путь>` | Путь к стартовому скрипту |

Допустима форма `--параметр=значение`. Неизвестные параметры, повтор
параметра, отсутствующее или пустое значение — ошибка (код возврата 2,
сообщение и строка `usage` в stderr).

При запуске выводятся отладочные строки со всеми параметрами:

```text
[debug] --vfs = examples/demo.json
[debug] --script = <not set>
[debug] vfs name = demo
```

### Стартовый скрипт

- Комментарии в синтаксисе Java: `// ...` в начале строки или после команды
  (`//` должно начинаться со слова и не находиться внутри кавычек).
- Пустые строки пропускаются.
- Каждая команда выводится после приглашения, затем её результат — как
  диалог пользователя с эмулятором.
- Ошибка команды (неизвестная команда, незакрытая кавычка) выводится, и
  выполнение скрипта продолжается со следующей строки.
- `exit` в скрипте завершает эмулятор; без `exit` после скрипта эмулятор
  переходит к интерактивному вводу.
- Если файл скрипта не найден или не читается: `error: ...` в stderr,
  код возврата 1.

Коды возврата: `0` — штатное завершение, `1` — ошибка чтения скрипта,
`2` — неверные параметры.

## Сборка, тесты, запуск

Нужен JDK 17 или новее и `make`.

```sh
make build            # компиляция в build/main
make test             # компиляция и запуск тестов
make run ARGS="--vfs examples/demo.json --script examples/startup.emu"
./run.sh --vfs examples/demo.json --script examples/startup.emu
```

Скрипты реальной ОС (bash), проверяющие все параметры командной строки:

```sh
./scripts/demo_basic.sh    # --vfs, --script, оба сразу, форма --опция=значение
./scripts/demo_quotes.sh   # кавычки в скрипте и интерактивный ввод после него
./scripts/demo_errors.sh   # ошибки параметров и содержимого скрипта
```

Примеры стартовых скриптов эмулятора лежат в `examples/*.emu`.

## Примеры использования

Интерактивный режим:

```text
$ ./run.sh
[vfs]$ ls
ls: []
[vfs]$ ls -l "my dir" 'a b'
ls: ["-l", "my dir", "a b"]
[vfs]$ cd "/tmp/x y"
cd: ["/tmp/x y"]
[vfs]$ cd "oops
error: unterminated double quote
[vfs]$ foo
foo: command not found
[vfs]$ exit
```

Запуск со стартовым скриптом `examples/startup.emu`:

```text
$ ./run.sh --vfs examples/demo.json --script examples/startup.emu
[debug] --vfs = examples/demo.json
[debug] --script = examples/startup.emu
[debug] vfs name = demo
[demo]$ ls
ls: []
[demo]$ ls -l /home
ls: ["-l", "/home"]
[demo]$ cd /home/user
cd: ["/home/user"]
[demo]$ exit
```

Ошибка параметров:

```text
$ ./run.sh --verbose
error: unknown option: --verbose
usage: emulator [--vfs <path>] [--script <path>]
```
